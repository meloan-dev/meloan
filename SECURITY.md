# Security

Do not post private keys, recovery phrases, access tokens or exploitable vulnerabilities in public issues. Use the repository owner's verified private contact or GitHub private vulnerability reporting when enabled; no security mailbox has been configured in this source.

This interface is unaudited. Wallet connection and balance reads are read-only, and lending execution remains disabled. Third-party prices and client-side checks do not replace onchain risk enforcement. Never use a security badge or passing CI as evidence of an audit.
